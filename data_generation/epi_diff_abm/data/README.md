# EpiABM Data Directory

This directory is intentionally empty in the code release except for this file.

Place downloaded and generated EpiABM/EpiCF data here before running the
calibration and cache-building scripts. Expected subdirectories include:

- `delphi_county_data/`
- `full_google_mob_data/`
- `networks/`
- `population_data/`
- `processed_data/`
- `state_data/`

The EpiCF county CSV files such as `multi_policy_data.csv` should also be placed
in this directory when reproducing the multi-county experiments.
