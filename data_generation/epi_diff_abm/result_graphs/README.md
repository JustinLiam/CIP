# EpiABM Calibration Results Directory

This directory is intentionally empty in the code release except for this file.

County-level calibration writes `calibrated_params.txt` under paths such as:

```text
result_graphs/<county>/202010-202104/0.0005_3_5_True_False/calibrated_params.txt
```

These calibrated outputs are generated artifacts and are not committed to the
repository.
